## Summary

Key plan that splits the electrical work by area: Service Area Improvements → E1.1, New Blower Building → E2.1/E2.2, Train No.3 → E3.1, Influent and Dewatering → E4.1, 2W Pump Station and Hotboxes → E4.3, UV Disinfection Chamber and Digester → E5.1 (plans_8 p.8) [Verified for the Blower Building and Influent callouts; others Verified-Visual]. General notes: conduit routing is not all shown and is schematic, equipment locations are schematic, and electric handholes are not shown but are required by code and Division 26, with final locations coordinated with the Engineer (plans_8 p.8) [Verified]. Key note 1: new SCADA computer system per specifications with final location in the lab coordinated with the Owner; new Cat 6 network junction box with combo network/telephone outlet; Cat 6 cabling to the network switch in the Influent Pump Station control panel; existing telephone circuit wired to the junction box for the SCADA alarm dialer; conduit S-LAB (plans_8 p.8) [Verified; S-LAB Verified-Visual]. The text layer also carries repeated LAMP/STATUS/TOP/BOTTOM/INLET/OUTLET strings from the background base drawing; they identify no electrical equipment, and the same strings recur on E0.4 (plans_8 p.8) [Inferred].
