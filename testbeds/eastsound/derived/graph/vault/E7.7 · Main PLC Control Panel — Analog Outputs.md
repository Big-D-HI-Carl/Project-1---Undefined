## Summary

One Allen-Bradley 1769-OF8 8-channel current output card on fused 24 VDC (FU-AO), 0.25 A fused terminal per channel (plans_11 p.4) [Verified]. Output 0: effluent sampler flow pace; output 1: sodium hypochlorite feed pump flow pace; outputs 2–7 spare (plans_11 p.4) [Verified-Visual; labels also in text]. No analog speed references go to the ten MCC VFDs; E9.2 key note 2 sends speed command and feedback to the PLC over Ethernet with no analog hardwiring (plans_11 p.4; plans_12 p.4) [Verified]. The two flow-pace outputs match E4.1 key note 6 and the E6.3 signal runs S-FP3 and S-FP4 to the main PLC control panel (plans_9 p.6; plans_10 p.4) [Verified].
