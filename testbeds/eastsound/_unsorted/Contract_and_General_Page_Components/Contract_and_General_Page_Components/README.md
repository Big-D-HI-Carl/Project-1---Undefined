# Contract & General — Components by Page

Eastsound WWTP Upgrade Phase I test bed. One file per source page that carries at least one Ledger component in this lane's stack (spec Divisions 00–01, Appendices D, E, I, Add. 4 p.1, QA plan).

- **Basis:** built from `Contract_and_General_Ledger.csv` — every page cited in the Source Citation or Addenda column. No page text was used to add components.
- **Named vs cited:** each component–page pair was checked against the page's stored text layer. "Named" (Verified) = the component's own term is on the page. "Cited; term not on page" (Inferred) = the cited clause covers it by category (e.g. "O&M manuals for all equipment", 01 70 00 ¶1.03.A.6) or the Ledger maps a differently worded item to it. Where a citation spans pages (e.g. pp.139–140), the component is filed only on the page(s) that name it.
- **Ledger tag** is the row's weakest tag from the Ledger; **Owning lane** comes from the row's "Cross-lane" note (none = Contract & General).
- **Limits:** a page that names a component without a Ledger citation has no entry here. Drawing sheets are not in this lane; per-sheet component files come from the other four lanes' ledgers.
- **Counts:** 39 page files · 49 components · 206 component–page entries (127 named, 79 cited but not named).
