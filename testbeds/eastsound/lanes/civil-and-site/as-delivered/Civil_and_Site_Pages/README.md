# Civil & Site — Pages

Eastsound WWTP Upgrade Phase I · Civil & Site lane · one file per drawing page in this lane's stack, as of Sep 30, 2026.

## How these files are built

- Each file carries front matter, the page's Wiki note (same format as Civil_and_Site_Wiki.md), the components on the page, and the issues that name the page.
- A component is listed on a page when the Ledger's Drawing Sheets column names that sheet. A component shown on several pages appears in each of those files, so page counts add up to more than the Ledger's row count.
- The 10 unavailable sheets get a stub: nothing was read on them, and the components listed are ones other documents tie to them (from Drawing Sheets or Notes).
- File names start with the set page number from the G0.1 index so they sort in set order; C1.6A (addendum-only, 'XX of 96') is 19A.
- Spec sections and appendices are not split into files; their components appear in the page tables through the Spec sections column.
- Tags link to the component wiki pages in Civil_and_Site_Components. Extract both zips into the same folder so the links resolve.
