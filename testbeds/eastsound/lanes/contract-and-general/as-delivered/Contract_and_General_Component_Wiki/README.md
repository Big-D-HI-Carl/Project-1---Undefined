# Contract & General — Component Wiki

Eastsound WWTP Upgrade Phase I test bed. One page per component in this lane's Ledger: what it is, what this lane's documents require of it, where it appears, and what is still open.

- **Basis:** each page is built from its Ledger row (fields and notes), the page index in `Contract_and_General_Page_Components/`, and `Contract_and_General_Issues.md`. Summaries are written from the Ledger notes; every claim carries its citation and tag.
- **Classifications:** Type and System group are groupings for navigation (Inferred), not source statements.
- **Page links** point to `../Contract_and_General_Page_Components/`; that folder ships in the same zip, so keep both folders side by side.
- **Scope:** components come only from this lane's stack (spec Divisions 00–01, Appendices D, E, I, Add. 4 p.1, QA plan). The owning lanes hold the design detail; this wiki records what the contract and general requirements say about each item.
