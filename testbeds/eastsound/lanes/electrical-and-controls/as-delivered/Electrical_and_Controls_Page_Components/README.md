# Electrical & Controls — Components by Page

One file per drawing page, per Division 26 section and per Addendum 4 page in the Electrical & Controls stack of the Eastsound WWTP Phase I bid set. Each file lists the Ledger components on that page, where the page shows them, and the Issues that cite the page.

- **Files:** 55 — 35 drawing pages (E0.1–E10.3), 14 Division 26 sections, 6 Addendum 4 pages. Built 2026-09-30 from `Electrical_and_Controls_Ledger.csv` (126 rows), `Electrical_and_Controls_Wiki.md` and `Electrical_and_Controls_Issues.md`.
- **Drawing pages:** a component is on a page when its Ledger "Drawing Sheets" column lists that sheet. "Where on this page" quotes the row's Source Citation for that sheet.
- **Specifications:** one file per section, not per spec page — requirements and the Ledger's Spec Sections column are section-level, and most rows cite no single spec page (assumption). The section's submittal and testing requirement is stated at the top.
- **Addendum 4:** pages 1–3 (items that 03 maps to this lane) and the rental generator exhibit, pages 11–13. A component is on a page when its Addenda or Source Citation cites that page.
- **Placement:** each file names its source PDF and page, so it can sit beside that document in the library without renaming or moving the source.
- **Tag level:** Verified = text layer · Verified-Visual = page image · Inferred = derived · Unresolved = conflict or gap (see Issues).
